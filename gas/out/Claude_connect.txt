Claude（月額プラン）から送迎表を相談・組み替える方法
================================================

■ できること
  Claudeアプリ（スマホ・パソコン）で「安達が休み。組み替えて」などと話すと、Claudeが送迎表を読んで組み替え案を作ります。
  案は送迎表画面の「🤖 Claudeの案」に届き、担当者が確認して「この案を反映」を押すまで送迎表は変わりません。
  料金は Claude の月額プランの範囲内です（1回いくら、はかかりません）。使える回数はプランの利用上限に含まれます。

■ 準備（管理者が1回だけ）
 1. 送迎表のスプレッドシートを開き、拡張機能 → Apps Script で、このフォルダの Mcp.gs と Lib4_engine.gs を追加（Code.gs ほかも新しいものに置き換え）。
 2. デプロイ → デプロイを管理 → 編集 → バージョン「新バージョン」→ デプロイ（URLは変わりません）。
 3. エディタで関数 issueConnectorUrls を選んで実行 →「AI接続」シートができます。
 4. 「AI接続」シートのA列に、Claudeで相談する人の職員番号を入れて、もう一度 issueConnectorUrls を実行 → C列に接続URLが入ります。
    （権限が「管理者」か「送迎表」の人だけ使えます。止めるときはD列に何か書く）
 5. 中継を作る（無料）：Cloudflare に登録 → Workers → 作成 → 「relay_cloudflare.js」の中身を貼って保存・デプロイ
    → 設定 → 変数 に GAS_URL = 送迎表のウェブアプリURL（…/exec）を入れる。
    ※ Googleは返事を必ず「転送(302)」で返すため、Claudeが直接つなげない可能性が高く、この中継で受け渡しします。中身は保存しません。

■ 各担当者のClaude（1人1回）
  Claude（claude.ai）→ 設定 → コネクタ → カスタムコネクタを追加
    名前: 送迎表
    URL : https://<中継の名前>.workers.dev/mcp/<接続URLの k= の後ろの文字>
  会話の「＋」→ コネクタで「送迎表」をオンにして話しかけます。

■ 気をつけること
  ・接続URLは合鍵と同じです。人に渡さない。漏れたら「AI接続」シートD列で停止し、行を消して発行し直す。
  ・Claudeが変えるのは「案」だけ。会話で「反映して」とはっきり言ったときだけClaudeが反映します。
  ・誰がClaudeで案を作り・反映したかは「変更履歴」シートに残ります。
